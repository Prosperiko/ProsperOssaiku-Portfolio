GIScopo — Automated Academic Report Engine

Spatial Data Pipeline & Report Generation

The Problem

Generating standardized spatial topology reports manually was a slow, error-prone process that bottlenecked spatial data analysis. Researchers and students spent hours formatting raw satellite data into usable academic reports.

The Solution

I engineered GIScopo, an automated web application deployed on Render that connects to Google Earth Engine API, ingests raw spatial data, and programmatically compiles it into clean, structured PDF reports with AI-generated insights and satellite imagery of specified locations.

AI Document Intelligence Engine

BYOK Architecture & RAG Pipeline

The Problem

Free-tier conversational AI platforms strictly limit document uploads and query volumes, leaving students and researchers blocked during critical study sessions. Users needed unrestricted access without hitting paywalls.

The Solution

I architected a custom web platform integrating OpenAI's API, Retrieval-Augmented Generation (RAG), and OCR scanning with a BYOK (Bring Your Own Key) model. Users plug in their own API keys and bypass standard subscription limits.
